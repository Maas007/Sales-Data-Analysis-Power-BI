# Sales-Data-Analysis-Power-BI
End-to-end Sales Performance Analysis built in Power BI using DAX, KPIs, and Root Cause Analysis to derive business insights

📊 Project Overview

This Power BI project presents an end-to-end Sales Data Analysis Dashboard designed to provide deep business insights through interactive visualizations and DAX-based KPIs.
It focuses on performance tracking, trend identification, and root cause analysis to help business leaders make data-driven decisions.

🎯 Objectives

Analyze overall Sales, Profit, and Quantity performance.

Identify top-performing products, categories, and regions.

Discover sales trends over time.

Perform Root Cause Analysis (RCA) to understand profit/loss variations.

Provide a clear, interactive, and dynamic report for management use.

⚙️ Tools & Technologies Used

Microsoft Power BI Desktop

Excel / CSV Dataset (for data source)

Power Query Editor (for data cleaning & transformation)

DAX (Data Analysis Expressions) (for calculated KPIs & measures)

🧩 Key Components of the Dashboard

KPI Cards: Total Sales, Profit, Quantity Sold, Profit Margin

Bar/Column Charts: Sales by Region, Category, and Sub-category

Line Chart: Monthly / Yearly Sales Trend

Pie/Donut Chart: Category-wise Contribution

Map Visualization: Sales distribution by geography

Root Cause Analysis Section: Identifies reasons for performance drop or growth

Slicers/Filters: Year, Product Category, Region, Segment, and Customer

🧠 DAX Measures Used

Total Sales = SUM(Sales[Sales Amount])

Total Profit = SUM(Sales[Profit])

Profit Margin = (Total Profit / Total Sales)

YTD, MTD, and YoY comparisons using Time Intelligence DAX

Cleaning and standardizing inconsistent sales data.
